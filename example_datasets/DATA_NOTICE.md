# Data notice

The files under `samples/` are tiny excerpts copied from the three project data roots solely so collaborators can inspect real layouts, pixel appearance, depth encoding, and label shapes. They are not a training split and must not be used for metrics.

The project repository does not grant any additional rights to the upstream datasets. Keep source attribution and licensing requirements when redistributing, publishing, or using the full datasets. Natural-language fields and per-frame target labels in these examples remain metadata/ground truth and are prohibited from OmTrackVLA model inputs.
