# 清洁感知模型的真实 RGB 接线验证

2026-09-14：12 项真实远端 CPU 集成测试通过；GPU7 上完成四个固定观测的 BF16 前向与反向，未创建优化器、未保存 checkpoint。原模型代码及权重未修改。

新图使用已固定的官方 DA3-SMALL 骨干，冻结全部骨干参数，重新初始化 296,711 个感知任务参数。输入只有首次 RGB/目标框与四帧因果 RGB 历史；初始化参考单独通过 DA3，目标 ROI 采用与旧实现一致的 aligned 3×3 RoIAlign。可学习投影和目标 query 每次重算，避免训练中缓存过期参数生成的模板。后续 GT 框、panoptic、目标坐标和教师动作均不进入 forward。

模型支持 dense 与 pooled 两种读出，用于后续同数据、同预算比较。目前只验证接口，没有训练出新模型，也没有两种读出的精度对照。该图是视觉感知预训练模块，尚无导航动作、UWB 绑定或主动搜索执行器。

`raw_episode.py` 从固定 supervisor SHA 所绑定的原始输入读取 RGB，以 OpenCV INTER_LINEAR 缩放到 280×504。初始历史补帧，之后仅访问当前及过去帧。标签读取是独立操作；可见性、框有效性分别返回，不制造身份、停车或动作监督。此版本明确 `optimizer_input_allowed=False`。

实际 GPU 检查使用 clean48 固定第一场景的观测 0、1、30、122，共四个可见性标签、三个框标签；帧 122 不可见，仅监督可见性。此前该轨迹独立原始数据核验已通过，但教师跟随质量未通过，因此本检查不构成训练数据准入。

官方骨干 437/437 权重张量形状匹配，参数覆盖率 100%。投影、空间匹配、局部框末层和可见性头梯度均有限且非零；局部框第一层初始梯度为零，原因是末层按模块设计零初始化，本轮没有优化器步骤。任务参数前后 SHA 完全一致，骨干无梯度。
