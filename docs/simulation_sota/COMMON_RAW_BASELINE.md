这四例是已用于开发的内部验证子集，来自官方 train 中永久保留的两个场景，不是官方 1,405 集。它们没有可见干扰人物，不能证明同身份确认或抗干扰能力。90.67% 的整体可见性准确率受 177 帧负例占比影响，不能代替定位或跟随成功率。

输入使用同一批新采集 raw RGB。复用真实 `ArchitectureV1HabitatController` 的 OpenCV INTER_LINEAR 预处理、四帧初始填充、hidden state 与 target memory；每例重置，随后只传当前 RGB，UWB 缺失。只允许原来的首次 RGB+bbox 初始化和静态相机标定。GT 仅用于生成清单和独立评分，推理不读取后续标签或 panoptic；不执行预测动作。终末帧保留在标签中但不推理。

原始老视频带绘制叠加，缺少所有帧的原始像素和原始 worldtime 参照。本次不声称重放了完全相同的旧像素/时钟；后续候选应在这批相同 raw 历史上比较，并另跑闭环检验。固定动作历史的感知分数不是候选模型的闭环成绩。

21 项不同 CPU 边界/因果测试在本机和远端通过。首次远端测试有 14 个 fixture 路径错误、7 项通过；已备份旧测试文件，安装兼容目录的测试文件后重跑全部 21 项通过，首轮失败日志保留。CPU 预检校验 595 个代码及骨干文件，并重读 225 张输入图片。真实推理四例均完成、无异常；0 optimizer step，没有保存新权重，父 checkpoint 哈希未变。实际运行墙钟 9.189 秒不含前置哈希校验；它不是机器人端到端时延测量。
