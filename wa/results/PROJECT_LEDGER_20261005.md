## 📥 输入与输出

以下模型、训练规格沿用既有实现与训练记录；本轮未重新训练或逐项重新测量模型规模。

| 输入 | 实现 |
|---|---|
| 环境 | 前向单目 RGB，224×224 |
| 历史 | 4帧因果历史，约 −1.5、−1、−0.5、0秒已有观测 |
| 视觉目标 | 首帧人物 GT BBox 裁剪模板；不持续提供真值框 |
| 坐标目标 | 机器人局部极坐标 [r,θ]，米／弧度，前方0、左正 |
| 时间 | 图像／UWB 时间戳、有效性和数据年龄 |
| 文本 | 无文本，不调用语言模型 |

image／point／mixed 均有离线验证；point 仍使用 RGB 感知环境，不是仅靠坐标。当前主要闭环成绩属于 mixed，不能作为 point 独立闭环结论。UWB 由模拟机器人与目标位置生成，噪声0、延迟0，尚未验证实际测量、丢包、多径及漂移。

输出未来0.1～0.7秒的7个局部 SE(2) 点 [x,y,sin(yaw),cos(yaw)]，以及目标几何估计。控制器转为 [-1,1] 内前后／左右／转向分量；模型轨迹、归一化控制量和实际速度不是同一种单位。

语义传感器使用模拟器真值，不是学习式检测器。它用于初始目标框及评测可见性；语义图本身不输入策略。最新7条修复只替换对应首帧的零目标框，不提供后续 GT 框，也不引入未来目标或 GT 路径。

## 🧠 模型架构

| 组件 | 实现 |
|---|---|
| 编码器 | 官方预训练 DINOv2-S/14，冻结 |

既有损失配置：动作 Flow＋0.5×目标几何＋0.1×潜在动力学。既有记录联合模型约3.85亿参数，包含冻结编码器和训练辅助；不等于单个世界模型规模，也不代表端侧已可部署。
