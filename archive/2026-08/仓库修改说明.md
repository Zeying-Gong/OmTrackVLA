# OmTrackVLA 相对原仓库的修改说明

基线：`origin/main`（commit `a667bf7`）。以下只列代码、脚本和配置相关修改，不包含 `sim_data/` 等评测产物。

## 会影响评测行为的修改

### `habitat-lab/habitat/tasks/track/track_task.py`

- 原实现只在 worker 的第一个 episode 调用 `_switch_avatar()`；修改为每个 episode reset 时都按 `episode.info` 切换主目标人物和其他人物。
- 将 avatar 切换顺序改为先执行 `sim.reset()`，再替换 humanoid，避免场景 reset 覆盖刚创建的人物对象。
- 新增 `_semantic_id_for_humanoid()`，从 `humanoid_infos.json` 查询人物 semantic ID。
- 新增 `_replace_humanoid()`，统一完成人物旧对象删除、URDF/motion data 加载、semantic ID 设置和 agent 引用替换。
- avatar 替换时同步重建对应的 `HumanoidRearrangeController`，避免新人物继续使用 YAML 默认人物的 motion controller。

### `evt_bench/additional_sensor.py`

- `MainHumanoidDetectorSensor` 原来只在第一次观测时读取一次 `main_human_semantic_id`。
- 修改为每个 episode 都从 `episode.info["main_human_semantic_id"]` 更新目标人物 ID，避免后续 episode 继续检测 worker 第一集的人物。

### `trained_agent.py`

- 在 episode reset 时清空 `frame_buffer`、`_coarse_hist_tokens` 和 `_last_predicted_traj`，避免上一 episode 的视觉历史进入下一 episode。
- 增加 `SAVE_VIDEO` / `TRACKVLA_SAVE_VIDEO` 开关，关闭视频时不再缓存和编码完整视频。
- 增加 `TRACKVLA_VERBOSE_STEPS`，控制逐步调试输出。
- 增加 `TRACKVLA_LIVE_FRAME_INTERVAL`，可每隔指定步数保存机器人当前视角 JPG。
- 本地 Hugging Face checkpoint 加载时支持 `OMTRACKVLA_LLM_NAME` 覆盖 LLM 路径。
- planner、vision encoder 初始化或推理失败时输出实际异常；planner 没有返回 action 时直接报错，不再静默继续。
- 增加可选 `TRACKVLA_AGENT=flux` HTTP agent 路径；默认仍使用 OmTrackVLA agent。

### `run_eval.py`

- dataset split 增加 `allow_uneven_splits=True`，保证 1405 个 episode 在不能整除 chunk 数时不丢失 episode。
- 增加 `--max-episodes`，用于小样本 smoke test。
