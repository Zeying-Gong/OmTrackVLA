# 实例修复后的评测口径

目标是验证对指定物理目标的跟随能力。当前没有 SOTA 成绩；修复评测标签本身也不构成模型效果提升。

旧版与修正版数据、传感器编号生成方式、指标和 checkpoint 必须分别保存。旧编号下得到的感知 IoU、visibility、facing、following 和 success 数值仍可复算，但真实物理实例独占性未成立，不能直接用来选择下一轮训练权重。几何位置与时间信息按各自证据单独使用。

修正资产加载方案必须先用真实渲染证明：指定 actor 单独可见时，其像素使用该 actor 的编号；其他 actor 不产生主人物编号。相同 avatar 的多个实例必须包含在测试中。资产模型、骨骼、动作文件、相机、种子及物理参数的变化要分别记录。属性读回与程序正常退出均不能代替渲染证据。

若控制器使用了旧 mask，修正身份会改变它的动作决策。新的教师轨迹应按独立版本重新采集；不能把不同轨迹的新 mask 当成旧 RGB 的标签。确需重标旧图时，要先证明重放的原图、时刻和物理状态匹配，并记录无法匹配的案例。

修正后的跟随评测应让 OmTrackVLA、LightNav 和其他基线使用同一实例生成方式、同一任务集合与失败分母，以及明确的目标指定、相机、时间和动作条件。所有模型均重新运行，不能把修正版成绩和别人采用旧原生语义链的公开数字直接排在同一榜上。

若为复现公开原生 EVT 成绩而保留原生协议，应单独命名、固定源码并报告其已发现的实例标签限制。修正物理实例协议下的同条件比较，是另一组有明确环境差异的实验。两组结果不混算。

开发集调参、正式验证和受保护测试拆分继续分开。原 4 case / 2 scene 开发集的反复观察不构成正式验证；训练拟合、单例成功、原始数据哈希通过或某个优化器完成，都不构成 SOTA。

本文件只规定后续结果的解释和比较方式；没有授予新数据、教师动作或优化器资格，没有修改原冻结 grant，也没有启动 GPU。
