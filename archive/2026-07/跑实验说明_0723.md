## 2. RGB-D 数据格式

原始 0420 数据以每个 episode 一个 RGB MP4 和一个 `*_info.json` 的形式发布。FLUX
训练需要随机读取 8 帧历史 RGB、当前深度和未来轨迹，因此重新采集的数据直接保存为图片：

```text
omtrackvla_flux_rgbd_0420_v7/
  stt|dt|at/<scene>/<episode>/
    rgb/000000.jpg
    depth/000000.png
    frames.jsonl
    complete.json
```

- RGB：384 x 384 JPG。
- Depth：384 x 384、uint16 PNG，单位为毫米。
- `depth_scale=1000`，读取米制深度时执行 `depth_m = png / depth_scale`。
- 采集层保存原始深度，不执行 1.7 m 或 5 m 裁剪。
- FLUX dataset loader 在送入模型前再执行官方预处理：小于 0.1 m 或大于 5 m 置零。
- RGB 和 Depth 的位置、朝向、父 link、分辨率和 HFOV 已完全对齐。
- 人物每帧平移位置由原始 `*_info.json` 恢复，避免分片改变 RNG 后人物轨迹与动作标签错配。
- `complete.json` 是 episode 完成标记，也是断点续采依据。

关键代码：

```text
replay_rgbd.py
replay_rgbd_0420.sh
collect_rgbd_0420_8way.sh
```

## 3. GPU 渲染 smoke

全量采集前，先提交一个单机 8 卡任务。该命令每个 shard 采一个 episode，共 8 个：

```bash
cd /robot/robot-research-exp-0/user/gzy/OmTrackVLA

TASK=stt \
GPU_LIST=0,1,2,3,4,5,6,7 \
MAX_EPISODES=1 \
DISPLAY_BASE=99 \
RUN_ID=stt_gpu_smoke8 \
OUTPUT_ROOT=/robot/robot-research-raw-data-0/user/gzy/omtrackvla_flux_rgbd_smoke8 \
bash collect_rgbd_0420_8way.sh
```

必须在 worker 日志中确认：

```text
Renderer: NVIDIA ...
```

如果显示 `Renderer: llvmpipe`，当前使用的是 CPU 软件渲染，不适合全量采集，也可能因
GPU 利用率为零被集群回收。`collect_rgbd_0420_8way.sh` 默认使用 `run_xvfb.sh` 的 NVIDIA
OpenGL。`run_glx.sh` 仅作为排错回退方案。

日志目录：

```text
logs/replay_rgbd/full_stt_stt_gpu_smoke8/
```

## 5. 采集进度与完整性检查

分别统计完成 episode：

```bash
ROOT=/robot/robot-research-raw-data-0/user/gzy/omtrackvla_flux_rgbd_0420_v7
find "$ROOT/stt" -name complete.json | wc -l
find "$ROOT/dt" -name complete.json | wc -l
find "$ROOT/at" -name complete.json | wc -l
```

检查是否混入旧 schema：

```bash
rg -L '"schema_version": 6' \
  /robot/robot-research-raw-data-0/user/gzy/omtrackvla_flux_rgbd_0420_v7/*/*/*/complete.json
```

正常情况下该命令不应输出任何文件。每个 episode 还应满足：

- RGB 数量等于 Depth 数量。
- RGB/Depth 数量等于 `frames.jsonl` 行数和 `saved_frames`。
- `mean_replay_robot_planar_error_m` 接近零，且 `replayed_steps == source_steps`。
- Depth 没有 uint16 饱和。
- RGB 人物轮廓与 Depth 边界像素对齐。

当前通过验证的单 episode 指标：

```text
RGB / Depth / manifest: 33 / 33 / 33
mean planar replay error: 1.65e-6 m
max planar replay error: 5.12e-6 m
uint16 depth saturation: 0
```
